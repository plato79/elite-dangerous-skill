# INARA and Coriolis reference

## INARA

- Developer guide: https://inara.cz/elite/inara-api-devguide/ . To register an app, contact INARA's author with the exact app name, purpose, a short description, and optional homepage. A personal key does not eliminate app-name allowlisting. The helper does not claim to be another whitelisted app.
- Personal API key: https://inara.cz/elite/cmdr-settings-api/ . Set `INARA_API_KEY` privately in the environment. `INARA_APP_NAME` is the exact approved app name. On Windows, the helper checks the current user's persistent environment if not inherited. Never put the key in chat, command arguments or skill files.
- POST uncompressed JSON to https://inara.cz/inapi/v1/ with header appName, semantic appVersion, APIkey, optional journal-confirmed commanderName and isBeingDeveloped, and an events batch. Use actual UTC ISO 8601 timestamps. API JSON header and each event have separate statuses: 200 success, 202 warning, 204 no results, 400 error. HTTP status and API status are distinct. Never print a key or raw error body.
- `getCommanderProfile` returns basic information, not full inventory or fleet; no searchName plus personal key requests the current user's profile. Named searches can fall back to nonexact matches. https://inara.cz/elite/inara-api-docs/
- INARA excludes market, station, system and faction-influence outputs from the API. Use its website or another appropriate source, accounting for age. Write events can replace or modify account state; require explicit approval and read back the exact target. This helper has no write mode.
- `isBeingDeveloped: true` is appropriate while testing, but it suppresses only specified global updates such as `setCommunityGoal`; it does not make personal write events safe or read-only. Future synchronization must batch events, avoid repeats, exclude legacy/beta game data, respect rate limits, map journal events to the API schema, and never send partial replacement inventories or statistics. A 400 header can omit `events` entirely; check it before parsing the events. The explicit message `This application has no access allowed.` means the configured application is denied; do not assume the API key itself is invalid or retry without changing the conditions.

## Coriolis

- EDMC constructs `https://coriolis.io/import?data=` plus gzip-compressed, URL-safe Base64 JSON. The helper mirrors the public implementation. Sources: https://github.com/EDCD/EDMarketConnector/blob/main/plugins/coriolis.py and https://github.com/EDCD/EDMarketConnector/blob/main/plugins/common_coreutils.py .
- Settings → Import accepts raw journal Loadout and SLEF. SLEF is an array of entries with `header` (required `appName`, `appVersion`) and `data` (required `Ship`, `Modules`, each with `Slot` and `Item`; present engineering requires `BlueprintName`, `Level`, `Quality`, `ExperimentalEffect`). A full journal Loadout can serve as data. INARA also accepts SLEF posted as `externalslefimport` to the export's `appURL` while the ship's owner is logged in; this updates the ship and requires explicit user approval. The Coriolis URL carries the full loadout, so opening or sharing discloses encoded ship data. Inspect module/engineering mapping after import; unsupported components may be omitted. Sources: https://github.com/EDCD/coriolis/blob/master/src/app/components/ModalImport.jsx and https://inara.cz/elite/inara-impexp-slef/ .
- Detailed Coriolis exports include `references[0].url` and code. Do not fabricate an outfitting `code=` URL or assume changing exported names updates the encoded build.
- CMDR-Coriolis supports authenticated shortlink retrieval for linked/synced builds: `GET https://cmdr.coriolis.io/api/shortlink/<key>/slef/` or `/json/`, using `CORIOLIS_API_KEY` as the bearer token. The helper `scripts/coriolis_api.py` makes this read-only request; it accepts a shortlink key, not an arbitrary URL. The shortlink key differs from the API credential but can still reveal build information and should be treated as sensitive. It is not an anonymous resolver or a general fleet API; do not confuse its token with the INARA key. Sync can modify account state and requires explicit consent. Sources: https://github.com/EDCD/coriolis/issues/864#issuecomment-6898247886 and https://github.com/EDCD/coriolis/blob/master/CMDR.md .

- If the API returns Cloudflare HTTP 403 error 1010, it is a client signature block, not proof of an invalid key. Do not repeatedly retry or bypass the service's access controls. Ask the operator to allow the client or use the authorized website/account instead.

## Journal

Frontier reference: https://hosting.zaonce.net/community/journal/v38/Journal_Manual_v38.pdf . Select by event timestamp, not modification time. Cargo snapshots may describe ship or SRV. A ship's latest Loadout can be stale after other events or incomplete logs; timestamp it and don't infer unrecorded current state.
